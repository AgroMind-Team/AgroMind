# 🌾 AgroMind

AgroMind is an AI-powered crop recommendation and agricultural analytics platform built using Flask and Machine Learning.

## Features

- 🌱 Crop recommendation
- 📈 Production prediction
- 📊 Crop analytics dashboard
- 🌾 Planting guide
- 📰 Community feed
- 🌙 Dark mode UI

## Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- Scikit-learn
- Pandas

## Project Structure

```
Crop/

├── app.py

├── static/
│   ├── css/
│   └── js/

```

## Run

```bash
pip install -r requirements.txt
python app.py
```
